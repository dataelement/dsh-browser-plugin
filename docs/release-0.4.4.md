# 0.4.4 正式版宿主发送修复

验证日期：2026-11-04（America/Los_Angeles）。

## 修复

0.4.3 依赖开发宿主新增的 Send/Stop 标记。正式安装的 BISHENG 与 DSH Desktop 的 conversation 组件没有此标记，因此批注提交一直禁用。0.4.4 优先保留显式标记协议，并用宿主公开的 conversation 语言服务和原生按钮 accessible name 适配已发布宿主，不要求修改应用程序文件。

仅覆盖已识别的发送按钮；停止生成仍由宿主处理。监听主按钮节点替换、按钮名称／语言变化和编辑器锁定。退出／卸载撤销插件标记。未知或歧义按钮不允许发送。

## 验证结果

- 本机插件完整测试 86/86 通过，0 失败、跳过或取消（24.7 秒）。包含空正文批注发送适配、Send/Stop 切换及节点替换、排队／插话、宿主语言切换、未知／重复入口、卸载清理，以及已有截图／元素／批注／附件提交、失败重试、真实归档和严格 pnpm 安装测试。
- BISHENG 正式安装的 `@deepseek-ai/dsh-client-ui-conversation@0.2.1-rc.2`：确认没有开发标记。通过应用原生插件管理器从本地 0.4.4 压缩包更新并启用；使用 Harness 菜单的普通重启加载新版本。仅刷新页面会继续使用服务端缓存的旧插件，所以更新后需要重启 Harness。
- 在后台浏览器连接真实 BISHENG 新建验证会话，打开仅含测试数据的本机网页，选择按钮写批注，保存截图并与输入框文字一起点击发送。实际模型为 `dataelem / gpt-6.1-sol`，无模拟模型。
- 模型回复：按钮文字“发布预览 73”，完成数量“46”。其中完成数量来自选中元素之外的截图内容。会话已完成，未调用工具；草稿清空，待发批注 0、已发送记录 1，已发送注释浮窗可查看原截图。聊天正文显示可读批注摘要，元素证据留在详情内。
- 安装前已有批注数据保留。未修改正式安装包、immutable generation 内文件、宿主补丁或模型配置。

本次桌面验收仅为 macOS BISHENG；不把单元测试结果推断为其他平台或未来宿主的验收结果。此前 CI 的 Linux 沙箱与 Windows 未完成验证限制仍见 standalone-validation.md。
